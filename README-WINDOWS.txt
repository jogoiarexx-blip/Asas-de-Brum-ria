ASAS DE BRUMÁRIA v1.4.0 — VERSÃO WINDOWS

1. Extraia todos os arquivos do ZIP em uma pasta.
2. Execute JOGAR-WINDOWS.bat (Windows 10 ou 11).
3. O PowerShell abre um servidor local e seu navegador carrega o jogo. Não é um .exe nativo.
4. Internet é necessária no primeiro uso para o Three.js; o inicializador tenta guardar as bibliotecas em cache.

NOVIDADES v1.4.0: física de contato com inclinação do terreno e tração reduzida,
chefe gigante reage à posição do jogador dentro da arena e barcos geram ondas leves
ao afundar. Corrigida a animação de pouso que era sobrescrita pelo balanço.

CONTROLES: W/A/S/D mover/voar; espaço subir; CTRL descer; Q esquiva no ar;
F atacar; T estábulo; F3 diagnósticos; B comparação de FPS; G mudar gráficos.
Controles compatíveis com Gamepad API padrão; R3 esquiva, analógicos movem/câmera.
